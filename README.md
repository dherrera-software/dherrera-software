## 🚀 Proyectos destacados

### 🔄 [FileFlow](https://github.com/dherrera-software/FileFlow)
Conversor universal de archivos multipropósito con más de 35 formatos (documentos, imágenes, hojas de cálculo, presentaciones, audio y video). Monorepo con SPA en React 19 y API REST en Express, validación estricta de formatos, CORS restringido y limpieza automática de archivos temporales. Frontend desplegado en GitHub Pages y backend en Render mediante GitHub Actions.

`React 19` `TypeScript` `Tailwind CSS v4` `Vite` `Node.js` `Express` `FFmpeg` `Sharp` `GitHub Actions`

---

### 🧾 Sistema POS Aurora
Sistema punto de venta con gestión dinámica de mesas en tiempo real usando Canvas API, construido con arquitectura Next.js App Router para manejar estados complejos del flujo de ventas.

`Next.js` `TypeScript` `Canvas API` `Tailwind CSS`

---

### 🏢 ERP Interno de Gestión Administrativa
Módulos para gestión de contratos, salud ocupacional y documentación legal. Tablas de datos interactivas con consumo eficiente de APIs internas y modelado relacional SQL.

`Next.js` `PrimeReact` `SQL` `Tailwind CSS`

---

### 📄 facturacion-backend
Plataforma SaaS de facturación electrónica orientada a los estándares SUNAT (Perú). Arquitectura limpia en capas con autenticación JWT stateless, migraciones Flyway, mappers MapStruct y entornos Dockerizados.

`Java 21` `Spring Boot 3` `Spring Security` `JWT` `PostgreSQL` `Docker` `Flyway` `OpenAPI`

---

### 🕹️ [pong-modern](https://github.com/dherrera-software/pong-modern)
Juego Pong moderno con estética neon, multijugador local 1v1 y partidas cronometradas de 60 segundos, construido con MonoGame sobre .NET 8. Código modular con gestión de escenas, entrada y audio.

`C#` `.NET 8` `MonoGame`
